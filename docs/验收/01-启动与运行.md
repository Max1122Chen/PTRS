# 01 — 启动与运行

## 1. 环境要求

| 组件 | 版本（实测） | 说明 |
|------|--------------|------|
| JDK | **21** | `pom.xml` 中 `java.version=21` |
| Maven | 3.9+ | 构建与测试 |
| Node.js | 18+ | 前端 Vite 8 |
| MySQL | 8.x（**可选**） | 答辩演示可不启动 |
| Redis | 可选 | 未启用不影响 dev 演示 |

> 课程文档若写 Java 11 / Node 16，以本仓库**实际构建配置**为准。

---

## 2. 推荐：无数据库演示（JSON-only）

`application-dev.yml` 约定：

- `app.debug.ignore-db-connection-failure=true` — DB 连不上不阻断启动
- `app.storage.preload.enabled=false` — 不从 MySQL 预加载，仅用 seed + osm-data

### 启动

```powershell
# 项目根目录
mvn spring-boot:run "-Dspring-boot.run.profiles=dev"

# 新终端
cd frontend
npm install   # 首次
npm run dev
```

- 后端：<http://localhost:8080>
- 前端：<http://localhost:5173>（Vite 代理 API）

### 演示账号（dev-seed）

| 用户名 | 密码 | 角色 |
|--------|------|------|
| `dev_alice` | `dev123456` | USER |
| `dev_admin` | `admin123` | ADMIN |

## 3. 可选：连接 MySQL

1. 创建数据库并执行 `docs/sql/` 下迁移脚本（含室内、动画字段等）。
2. 在 `application-dev.yml` 或环境变量中配置数据源。
3. 将 `app.storage.preload.enabled` 设为 `true` 可在启动时从库加载（与 JSON-only 答辩模式二选一）。

---

## 4. AIGC 日记动画（FR-009-5）

代码已集成；**答辩前需自行配置密钥**：

1. 复制 `src/main/resources/config/jimeng-animation.example.yml` → 同目录 `jimeng-animation.yml`（已 gitignore）。
2. 填写火山引擎 `access-key-id` / `secret-access-key`；可选 LibTV 备用链。
3. 执行 `docs/sql/migration_add_animation_url.sql`（若使用 MySQL）。
4. 日记详情页触发生成，确认 `/media` 下视频可播放。

无密钥时：其余功能正常，动画接口会返回配置错误提示。

## 7. 常见问题

| 现象 | 处理 |
|------|------|
| 前端 401 | 使用 dev 账号登录；或确认 `application-dev.yml` 中鉴权配置 |
| 景区地图空白 | URL 需带 `areaId`（推荐 252 沙河）；确认后端已启动 |
| 设施/美食无数据 | 先选景区并等待地图 POI 加载，再在地图点击 POI 设锚点 |
| MySQL 报错但想演示 | 使用 **dev profile** + `ignore-db-connection-failure` |
