# 02 — 答辩演示脚本

> **建议时长**：主链路 15–20 分钟；动画/AIGC 另计 3–5 分钟。  
> **推荐样本景区**：`areaId=252`（北京邮电大学沙河校区，OSM canonical 包）

## 0. 启动前检查

- [ ] `mvn spring-boot:run "-Dspring-boot.run.profiles=dev"` 已运行
- [ ] `cd frontend && npm run dev` 已运行
- [ ] `python scripts/validate_s2_closure.py` 全 OK（可选）

---

## 1. 导航与推荐（约 3 分钟）

1. 打开 <http://localhost:5173/home> — 首页主标题 **travel**。
2. 点击 **开始游览** 或顶栏 **游览 → 推荐**。
3. 在推荐页切换 **热门列表 / 智能推荐**；登录 `dev_alice` 后演示个性化排序差异。
4. 点击任一景区卡片 **进入景区 →**，进入景区工作台。

**讲解要点**：一级导航为 首页 | 探索 | 日记 | 游览；游览分区二级为 推荐 | 景区 | 管理。

---

## 2. 景区一体化工作台 FR-017（约 8 分钟）

URL 示例：<http://localhost:5173/scenic?areaId=252&tab=route>

### 2.1 地图与锚点

1. 等待 ECharts 路网与 POI 加载。
2. **单击**地图 POI 设为锚点（设施/美食查询的基准点）。
3. 说明：设施/美食距离为**路网路径距离**，非 GPS 直线。

### 2.2 路线 Tab

1. 选起点、终点，交通工具（步行/自行车/电瓶车），策略（距离/时间）。
2. 演示 **两点规划**，地图上显示路径。
3. 演示 **多点规划**（选 3 个 POI）；若失败，说明会提示**不可达段**（POI 名称 + 原因）。

### 2.3 设施 Tab

1. 确认锚点已选（须先在地图点 POI）。
2. 选设施类别、半径，查询周边。
3. 列表按路径距离排序；地图**橙色高亮**设施节点；可点击设施设为新锚点。

### 2.4 美食 Tab

1. 基于同一锚点查看 Top 推荐或搜索。
2. 说明距离维度为路网距离，美食绑定餐饮类 POI。

### 2.5 室内导航 FR-004-5（沙河）

1. 在地图上找到 `indoorAvailable=true` 的建筑 POI（如图书馆等，沙河约 3 栋可用）。
2. **双击**进入室内分层图；切换楼层；选室内起终点规划。
3. 返回室外，锚点上下文保持。

**说明**：R8 室内 bundle 人工校正搁置，自动 OSM 归属仍有错位，演示以已入库 bundle 为准。
