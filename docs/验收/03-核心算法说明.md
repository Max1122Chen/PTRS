# 03 — 核心算法说明

> 课程约束：**检索在内存索引中完成**；核心图算法与检索索引的**实现主体**使用 `com.travel.ds`，不用 `java.util` 集合作为最终存储结构。详见 [Custom Data Structures Scope.md](../Tech/Custom%20Data%20Structures%20Scope.md)。

---

## 1. 总体数据流

```
dev-seed/*.json + osm-data/*/latest/*.append.json
        ↓  DevSeedDataLoader（启动）
   InMemoryStore（业务实体 + 索引）
        ↓
   Service 层编排 → 算法层（Dijkstra / TopK / Trie / NGram）
        ↓
   Controller → 前端 ECharts / 列表
```

- **持久化**：MySQL 可选；答辩 `dev` 模式以内存为准。
- **检索**：`PrefixTrieIdIndex`、`NGramInvertedIndex` 在 `InMemoryStore` 重建索引后查询，**禁止**用 SQL `LIKE`/`JOIN` 做模糊检索计算。

---

## 2. 室外最短路径 — Dijkstra

| 项 | 说明 |
|----|------|
| **代码** | `com.travel.algorithm.graph.Dijkstra` |
| **图结构** | `Graph` 邻接表，`Edge` 含距离、速度、`modeCongestion`（walk/bike/shuttle） |
| **权重** | 策略 `distance`：边长；策略 `time`：距离 ÷ min(道路速度, 交通工具速度) × 拥堵度 |
| **过滤** | `EdgeFilter` 按交通工具剔除不可通行边 |
| **调用** | `RouteServiceImpl`、`FacilityServiceImpl`、`FoodServiceImpl`（路径距离）、`IndoorPathPlanner`（室内图复用同一 Dijkstra） |

**复杂度**：单源最短路 O((V+E) log V)，优先队列为 `com.travel.ds.PriorityQueue`。

**示例（概念）**：沙河校区 POI A→B，步行策略下沿路网边累加距离，返回 `PathResult.path = [nodeId…]` 与 `totalWeight`。

## 3. 多点游览顺序 — TSP（状态压缩 DP）

| 项 | 说明 |
|----|------|
| **代码** | `RouteServiceImpl.solveOptimalMiddleOrder` |
| **问题** | 固定起点与终点（或回环），中间点全排列求最优访问顺序 |
| **方法** | 预计算点对最短路矩阵 → 位掩码 DP（中间点 ≤20） |
| **拼接** | `stitchPathByWaypoints` 按最优顺序逐段 Dijkstra 拼接完整路径 |
| **失败提示** | 不可达时抛出含 POI 名称的不可达段说明（S3-ROUTE-01） |

**未实现**：「景点覆盖最多」策略（FR-004 差距，答辩可口述为二期）。

## 4. 美食 Top-K — 小顶堆

| 项 | 说明 |
|----|------|
| **代码** | `com.travel.algorithm.TopKSelector` |
| **思路** | 维护大小为 K 的小顶堆，堆顶为当前 TopK 中最差项；遍历候选 O(n log K) |
| **调用** | `FoodServiceImpl` 对加权得分排序后的候选取 TopN |
| **得分** | 含匹配度、热度、评分、**路网路径距离**（相对锚点 POI） |

## 5. 内存检索索引

### 5.1 前缀 Trie — `PrefixTrieIdIndex`

- **用途**：设施/美食名称、菜系等**前缀匹配**。
- **结构**：字符 Trie，`com.travel.ds.HashMap` + `ArrayList` 存候选 id。
- **代码**：`com.travel.storage.search.PrefixTrieIdIndex`

### 5.2 N-Gram 倒排 — `NGramInvertedIndex`

- **用途**：设施/美食/日记**模糊检索**；query 切分为 2–3 gram，统计命中次数排序。
- **结构**：`term → List<id>` 倒排表。
- **代码**：`com.travel.storage.search.NGramInvertedIndex`
- **日记**：`InMemoryStore` 中全文索引；单字查询回退线性扫描（索引最小粒度为 2）。

### 5.3 个性化推荐（补充）

- `RecommendationServiceImpl`：基于用户兴趣标签与景区标签权重向量匹配 + 热度/评分加权（非 SQL 检索）。

## 7. 自制数据结构 `com.travel.ds`

| 结构 | 用途 |
|------|------|
| `ArrayList` / `List` | 路径、邻接边列表、候选集 |
| `HashMap` / `Map` | 邻接表、距离表、倒排表 |
| `PriorityQueue` | Dijkstra、TopK |
| `HashSet` | keySet 等 |

**边界**：Service/VO 层可用 JDK 集合；`DsConvert` 在入图/出 VO 时转换。  
**测试**：`CustomDataStructuresParityTest`、`DijkstraTest`、`TopKSelectorTest`、`SearchIndexTest`。

```powershell
mvn -q "-Dtest=CustomDataStructuresParityTest,DijkstraTest,TopKSelectorTest,SearchIndexTest" test
```
